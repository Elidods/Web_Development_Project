# Web_Development_Project
## Marrow & Ember Coffee Roastery Website

## Project Overview

Marrow & Ember is a responsive multi-page coffee roastery website developed using HTML, CSS, and JavaScript. The website provides customers with information about the coffee shop, menu, online shopping, contact details, shopping cart, and checkout process. It demonstrates modern front-end web development practices, responsive design, accessibility features, and client-side interactivity.

The project contains six primary webpages: Home, Menu, Shop, Cart, Checkout, and Contact. The shopping cart and checkout functionality are implemented entirely on the client side using JavaScript and browser localStorage, without requiring a backend server. :contentReference[oaicite:0]{index=0}

---

## Features

- Responsive multi-page website
- Modern coffee shop interface
- Mobile-friendly navigation menu
- Product menu filtering
- Online shopping functionality
- Shopping cart management
- Checkout form validation
- Contact form validation
- LocalStorage-based cart persistence
- Accessible HTML structure
- Consistent navigation across all pages

## Website Pages

### 1. Home (index.html)

The landing page introduces Marrow & Ember Coffee Roastery and includes:

- Hero section
- Coffee roastery story
- Interactive roast curve illustration
- Navigation menu
- Call-to-action buttons

---

### 2. Menu (menu.html)

Displays available drinks and pastries including:

- Coffee
- Cold Brew
- Pastries

Features:

- Category filter buttons
- Dynamic filtering using JavaScript
- Responsive menu layout

---

### 3. Shop (shop.html)

Allows customers to purchase coffee products online.

Products include:

- Coffee bags
- Espresso blend
- Pour-over kit
- Gift box

Features:

- Add to Cart buttons
- Product information
- Shopping cart integration

---

### 4. Cart (cart.html)

Displays all products added to the shopping cart.

Features include:

- Dynamic cart items
- Quantity management
- Remove products
- Subtotal calculation
- Checkout button

Cart data is stored using browser localStorage.

---

### 5. Checkout (checkout.html)

Provides a simulated checkout experience.

Features:

- Customer information form
- Order summary
- Client-side validation
- Order confirmation
- Cart clearing after order completion

No real payment gateway or backend is implemented.

---

### 6. Contact (contact.html)

Allows visitors to contact the coffee shop.

Includes:

- Contact form
- Form validation
- Business address
- Opening hours
- Wholesale enquiry information
